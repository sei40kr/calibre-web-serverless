# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's [private vulnerability reporting](../../security/advisories/new)
instead, with the steps to reproduce it and the impact you expect.

Only the latest commit on `master` is supported; fixes are not backported.

## Security model

[docs/security.md](docs/security.md) describes how the app authenticates
requests, the trade-offs already known (OPDS Basic authentication among them)
and the improvements planned.
